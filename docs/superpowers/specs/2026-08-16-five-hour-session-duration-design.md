# 5시간 세션 자동 종료 정책 설계

## 목표

산책 기록을 잊고 켜 둔 경우의 보호 정책을 전체 3시간에서 5시간으로
확대하되, 종료 직전 안내·자동 저장·자동 종료의 동작과 사용자에게 보이는
문구가 같은 기준을 사용하도록 한다.

## 범위

- 전체 세션 제한을 `5시간`으로 변경한다.
- 종료 예고를 `4시간 45분`에 한 번 표시하고 OS 알림으로 보낸다.
- 제한 도달 시 현재 기록을 자동 저장한 뒤 세션을 종료한다.
- 한 장소 정지 정책(`20분` 경고, `30분` 자동 저장·종료)은 변경하지 않는다.
- 도메인 기본값, 컨트롤러 문구, 단위·흐름 테스트, PRD/TRD 및 릴리즈 문서를
  같은 정책으로 갱신한다.

## 비범위

- 5시간을 넘겨 계속 기록하는 선택 기능 추가
- GPS 수집 주기·배터리 정책 변경
- 기존에 저장된 세션 데이터의 마이그레이션

## 동작 기준

1. 세션 나이가 4시간 44분 59초 이하면 자동 종료 경고를 내지 않는다.
2. 세션 나이가 4시간 45분 이상 5시간 미만이면 경고를 한 번 표시한다.
3. 세션 나이가 5시간 이상이면 자동 저장·종료를 실행한다.
4. 자동 종료 성공 시 완료 알림 문구에 `5시간`을 포함한다.
5. 자동 저장 실패 시 기존 복구 가능한 상태와 오류 알림 동작을 유지한다.

## 검증 기준

- 도메인 테스트가 4시간 45분 경고, 남은 15분, 5시간 제한을 검증한다.
- 컨트롤러 흐름 테스트가 경고 문구·자동 종료·완료 알림을 검증한다.
- Flutter 전체 테스트, 정적 분석, PRD/TRD 구조 검증을 통과한다.
- 변경 후 작업 트리가 의도한 커밋으로 깨끗하다.
