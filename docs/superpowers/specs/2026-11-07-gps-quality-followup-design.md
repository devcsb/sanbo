# GPS 신뢰도와 계산 비용 후속 설계

2026-11-07. 상태는 연결 없이 수행하는 범위의 구현/검증 완료이며 [검증 기록](../verification/2026-11-07-gps-quality-followup.md)에 결과를 정리했다.
사용자는 후속 과제를 계속 진행하라고 했으며 Galaxy S26 실측은 나중으로
미루고 연결 없이 가능한 작업을 먼저 하라고 했다. 기존 Flutter/Dart, 원본 GPS와
사용자 수정 보존, 앞뒤 걷기를 같은 산책으로 묶는 결정을 유지한다.

사용자 지침의 가역 작업 자율 진행에 따라 이 문서와 계획을 작성하고 같은 세션에서
구현한다. 아래 세부 감지 수치는 작성자의 보수적인 안내 기준이며 사용자가 직접
고른 수치나 물리 기기로 검증한 운동 판별 기준이 아니다.

## 이번 결과

1. 위치 오차 안에서 왕복하는 GPS가 이동 거리로 누적될 때 확인 안내를 제공한다.
2. 좌표와 제외 구간 수의 곱만큼 검사하는 경로 분할을 정렬 후 순회로 바꾼다.
3. S26 배터리/GPS 비교 측정 절차와 CARTO 키 방어의 다음 경계를 정리한다.

GPS 흔들림 감지는 자동 제외나 데이터 보정이 아니다. 같은 좌표가 실제 짧은 왕복일
수도 있기 때문에 원본/거리/이동 시간/지도/재생을 변경하지 않는다. 고속 자동 제외,
위치 요청 간격, Samsung 복구와 WakeLock도 실측 없이 바꾸지 않는다.

## 감지와 저장

새 처리 또는 사용자가 요청한 재계산에서, 한 분의 포함된 좌표를 시간순으로 본다.
원래 자료를 바꾸거나 과거 기록을 열 때 다시 저장하지 않는다.

- 좌표 최소 5개, 관측 기간 30초 이상, 이웃 관측 간격은 0초 초과 30초 이하.
- 모든 좌표/정확도가 유효하고 정확도는 0m 초과 150m 이하다.
- 의미 있는 선분은 1.5m 이상이며 합계는 10m 이상이다.
- 각 이동과 첫 좌표에서의 최대 이탈이 대표 정확도 반경 안에 있고,
  처음과 마지막 직선 거리가 선분 합계의 25% 이하다.
- 120도 이상 방향 반전이 두 번 이상이다. 작은 각도로 도는 정상 원형 경로는
  이것만으로 흔들림이라고 표시하지 않는다. 날짜 변경선의 경도 차이를 정규화한다.
- 양의 provider 속도가 0.5m/s 이상인 좌표가 있으면 이 안내를 적용하지 않는다.
  speed=0은 Android에서 속도 정보가 누락된 경우에도 나타날 수 있어 정지의 증명으로 쓰지 않는다.

조건이 모두 맞으면 `MinuteWindow.evidence`에 `gps_signal:jitter_suspected_v1`을
저장하고 활동 추정은 확신 0.25의 ‘알 수 없음’으로 표시한다. 거리, 시간, 품질 등급과
원본 좌표는 유지한다. 새 열/백업 버전/마이그레이션은 필요하지 않다. 사용자 확정
라벨은 기존 계약대로 우선하며 제외됐거나 사용자가 확인한 분에는 확인 안내를 반복하지 않는다.

이 기준은 모든 GPS 노이즈를 찾지 못한다. 표본이 적은 절전 모드, 단방향 드리프트,
정확도가 없는 기록은 자동으로 신뢰할 수 있다고 판정하지도 않는다.

## 화면과 카피

완료 상세에서 현재 포함되고 미확정인 의심 구간이 있으면 ‘GPS 확인이 필요한 구간이
있어요’와 거리/속도에 흔들림이 포함됐을 수 있다는 설명을 보인다. 기존 고속 제외
안내와 같은 패널에 묶고 ‘구간 살펴보기’ 동작을 재사용한다. 분/구간 부제에는
‘GPS 확인 필요’를 표시한다. 기계용 evidence 코드는 제품 화면에 노출하지 않는다.

큰 글자와 다크 테마, 기존 짧은 모션과 동작 줄이기, 48px 버튼을 유지한다. 새 이미지
에셋과 SDK는 필요하지 않다. 사용자가 활동을 확정하면 추가 수정 요구를 반복하지 않는다.

## 경로 분할 성능

샘플과 제외를 정렬한 뒤 포함 여부와 선분 교차 여부에 각각 전진 커서를 사용한다.
정렬 뒤 검사는 O(샘플 수 + 제외 수)다. 제외 시작과 같은 실제 좌표를 직전 정상
선분 끝점으로 보존하는 규칙, 반열린 범위, 겹치는 제외 거부, 필터/관측 공백 단절,
UTC 순간 비교와 원래 좌표는 그대로다. 이전 구현을 제한된 테스트 참고로 남겨
결정적 입력과 난수 입력의 결과를 대조한다. 벽시계 기준의 불안정한 속도 테스트 대신
호출 횟수 상한으로 반복 스캔 재발을 검사한다.

## 실측과 보안 경계

S26에는 사용 중인 최신 Android가 설치돼 있지만 버전 번호를 추측해 기록하지 않는다.
추후 모델/OS/build/app commit을 확인하고 정지/걷기/지하철과 모드별로 동일한 시간,
화면/배터리 조건에서 GPS 사용, CPU, 복구 횟수와 배터리를 비교한다. 기존 Samsung
fallback을 단순 삭제하거나 합성 CPU 결과를 배터리 절감률로 발표하지 않는다.

CARTO 공식 FAQ는 앱 제한용 공개 헤더를 요구한다. 공개 패키지와 인증서 헤더는
앱 진위의 암호학적 증명이 아니다. 키 난독화/교체/공개 프록시만으로 탈취와 남용을
막았다고 하지 않는다. 기존 앱 지도를 끊는 키 변경이나 결제/계정 설정은 이번에 하지 않는다.
계정 전체 상한과 앱 증명을 검증하는 서버 방안은 별도 운영 선택이다.

## 검증

정지 왕복 노이즈, 정상 직선/원형/짧은 왕복, 느린 걸음, 속도 누락/양수, 정확도
누락/비정상, 관측 공백, 필터/제외와 날짜 변경선을 검사한다. 동일한 GPS만으로 실제
왕복과 노이즈를 완전히 구분할 수 없음을 회귀에 명시한다. 저장/복원/사용자 확정과
제외 취소에서 원본과 수치를 보존한다. 상세 안내와 구간 링크를 작은 화면에서 검사한다.

근거는 [이전 제품 검토](../verification/2026-10-25-walk-value-audit.md),
[Android Location](https://developer.android.com/reference/android/location/Location),
[위치와 배터리](https://developer.android.com/develop/sensors-and-location/location/battery),
[CARTO FAQ](https://docs.carto.com/faqs/carto-basemaps)다. 2026-11-07 공식 내용을 다시
읽었다. accuracy는 68% 신뢰 반경이며 하드 경계가 아니다. Android 플러그인에
없는 speed가 Dart Position에서 0으로 바뀌는 것도 현재 잠금 소스로 확인했다.
