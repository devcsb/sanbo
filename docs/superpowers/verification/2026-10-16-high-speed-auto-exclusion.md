# 고속 자동 제외 개선 검증

2026-10-16 사용자가 승인한 짧은 설계에 따라 MR-09를 구현했다.
기준 브랜치는 `main`, 기준 커밋은 `5b2a0097578c81d33e739f3b34dc5e32bbe4fbba`다.
구현 브랜치는 `codex/high-speed-auto-exclusion-20261016`이다.

## 적용한 계약

- 필터 결과를 보존한 실제 GPS 선분에서 10km/h 이상 이동이 30초 이상 연속되어야 한다.
- 예상 오차는 양 끝점 모두 0~25m, 관측 간격은 0초 초과 30초 이하, 연속 좌표는 최소 4개다.
- 전체 기록 시간으로 자른 분 범위 전체를 하나의 연속 구간이 덮어야 한다.
  걷기와 고속 이동이 섞인 경계 분은 보존한다.
- 분을 감싸는 실제 선분의 순이동량은 거리 합의 60% 이상이며 끝점 예상 오차 합보다 커야 한다.
  왕복 흔들림과 강한 되돌림은 불확실한 경로로 남긴다. 새 경계 좌표를 보간하지 않는다.
- provider speed, 분의 최고 속도, 추정 vehicle 라벨은 단독 근거가 되지 않는다.
- 속도 검사는 새 기록 완료 때 적용한다. 완료 기록의 활동 편집은 방금 차량으로 확정한
  분에만 제외를 적용한다. 확정하지 않은 라벨은 자동 제외 근거가 되지 않는다.
- 기존 제외, 원본 GPS, 비차량 확정, 메모/장소와 제외 취소를 보존한다.
  다른 분을 편집하거나 차량으로 확정해도 취소했던 제외는 다시 만들지 않는다.
- DB schema 6과 백업 schema 2는 유지한다. 과거 기록을 일괄 재계산하지 않는다.

## 검증 범위와 남은 확인

합성 GPS, 실제 SQLite 저장소와 Flutter 화면을 검증했다. 물리 기기의 GPS 발생률,
정확도와 배터리는 이번 작업에서 실측하지 않았다. native 위치/알림 코드는 변경하지 않았다.
10km/h 이상 달리기도 속도 조건에 포함된다. 강한 되돌림과 일부 경계 분의 고속 이동은
보수적으로 포함할 수 있다. 원본 거리의 GPS 노이즈 보정(MR-08), 부분 제외의 레거시 표시
정합성(MR-15)은 이번 범위가 아니다. 단일 급증 사례의 거리 92.4m 자체는 변경하지 않았다.

현재 배포 버전 v0.9.2의 데이터나 공개 자산을 변경하지 않았다.
변경은 별도 PR에서 교차 검토한 뒤 병합/릴리즈 여부를 결정한다.
