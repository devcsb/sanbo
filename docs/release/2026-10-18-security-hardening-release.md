# 산보 0.9.4 보안 개선 릴리스 증거

2026-10-18 설계와 구현 계획을 사용자가 승인했다. 현재 `0.9.4+18` 후보를 준비 중이며
공개/병합을 완료했다는 문서가 아니다. [공개 APK 조사](../security/2026-10-18-public-apk-security-review.md)와
[운영 확인](../security/carto-operations.md)을 함께 따른다.

## 변경

- 변경된 CARTO 인증 안내 ETag와 weak ETag를 인식한다. 공급자 안내 이미지,
  산책 경로와 기록은 유지하고 안내 타일을 정상 지도처럼 캐시하지 않는다.
- 중립 `/tmp` 경로에서 clean commit을 빌드하고 모든 ABI APK/AAB의 개인 경로,
  비밀 파일과 기대한 클라이언트 키 포함 여부를 검사한다.
- 지도 영역/IP로 위치를 추정할 수 있다는 안내와 사용자 요청 주소 조회 안내를 추가했다.
- 스키마, GPS 계산/자동 제외 정책, 기존 서명 인증서는 변경하지 않는다.

## 남은 위험과 검증 한계

CARTO 클라이언트 키는 APK에서 계속 추출할 수 있다. 계정은 무료 비상업용이며 키는
현재 unrestricted다. 이번 작업에서 기존 키 제한/폐기나 유료 계약을 적용하지 않았다.
계정의 초과 처리/추가 청구/알림은 미확정이며 금전 손해 0원을 보장하지 않는다.
광고 도입 전 상업용 분류 변경과 건강 데이터 광고 이용 금지 조건을 확인해야 한다.

물리 Android 기기 검증: 미실행. 물리 iPhone GPS/배터리와 접근성 실사용은 미검증이다.
합성 GPS, 에뮬레이터, 단위 테스트를 물리 보행 정확도의 증거로 사용하지 않는다.
별도 독립 모델 검토는 사용자 재위임 금지에 따라 실행하지 않는다. 작성자 검토와
실제 게이트를 제공한 뒤 PR의 사람 검토를 거쳐 공개 여부를 결정한다.

## 구현 중 판단

- 전체 게이트는 변경 완료 뒤 한 번 수행하고 과제별로 RED/GREEN 표적 검사를 사용한다.
  반복 검사 금지 지침을 따른 판단이며, 무관한 기존 회귀는 최종 전체 게이트에서 발견될 수 있다.
- 별도 모델 재위임을 하지 않는다. 작성자의 사각지대가 남으므로 공개 전 사람 검토가 필요하다.
- 검사기는 ZIP64/multidisk를 거부하고 ZIP metadata 8MiB, 파일 2GiB, entry 256MiB,
  전체 비압축 1GiB, entry 10,000개로 제한한다. 향후 큰 정상 패키지는 별도 지원이 필요하다.
- 빌드 로그를 산출물 폴더 바깥 0600 sibling 파일로 보존한다. 실패 분석에 필요하며
  소유자가 삭제하기 전까지 남으므로 공개 릴리스에 첨부하지 않는다.
