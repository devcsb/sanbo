# 산보 0.9.4 보안 개선 릴리스 증거

2026-10-18 승인된 설계와 구현을 검증한 뒤, 2026-10-19 사용자의 배포 지시에 따라
[PR #3](https://github.com/devcsb/sanbo/pull/3)을 병합하고
[GitHub v0.9.4](https://github.com/devcsb/sanbo/releases/tag/v0.9.4)를 공개했다.
공개 시각은 2026-10-19 13:33:26 KST다. 스토어 제출이나 iOS 배포는 하지 않았다.
[공개 APK 조사](../security/2026-10-18-public-apk-security-review.md)와
[운영 확인](../security/carto-operations.md)에 남은 범위를 기록한다.

## 변경

- 변경된 CARTO 인증 안내 ETag와 weak ETag를 인식한다. 공급자 안내 이미지,
  산책 경로와 기록을 유지하고 안내 타일을 정상 지도처럼 캐시하지 않는다.
- 중립 `/tmp` 경로에서 clean commit을 빌드하고 모든 ABI APK/AAB의 개인 경로,
  비밀 파일과 기대한 클라이언트 키 포함 여부를 검사한다.
- 지도 영역/IP로 위치를 추정할 수 있다는 안내와 사용자 요청 주소 조회 안내를 추가했다.
- 스키마, GPS 계산/자동 제외 정책과 기존 서명 인증서는 변경하지 않았다.

운영 키를 정지하지 않았으며 시험 뒤 검증 후보를 복구하고 설치 APK 해시까지 비교했다.

Artist의 불투명 UUID는 보존했으며 UUID의 외부 상관관계 의미는 미검증이다.

## 남은 위험과 검증 한계

CARTO 클라이언트 키는 APK에서 계속 추출할 수 있다. 2026-10-18 읽은 계정은 무료
비상업용이며 키는 unrestricted였다. 초과 처리/추가 청구/상한/알림은 미확정이다.
키만으로 계정 관리나 결제를 탈취했다는 증거는 없지만 사용량 남용과 서비스 제한 위험은
남는다. 이번 작업에서 기존 키 제한/폐기나 유료 계약을 적용하지 않았다. 광고 도입 전
상업용 분류 변경과 건강 데이터 광고 이용 금지 조건을 확인해야 한다.

물리 Android 기기 검증: 미실행. 물리 iPhone GPS/배터리와 접근성 실사용은 미검증이다.
합성 GPS와 단위 테스트를 물리 보행 정확도의 증거로 사용하지 않는다. 별도 독립 모델
검토는 재위임 금지 지침에 따라 실행하지 않았다. 작성자가 diff를 검토했고, 후보/결과를
제공한 뒤 사용자가 배포를 지시했다. 별도 GitHub 승인 리뷰를 받았다고 주장하지 않는다.
iOS 배포 바이너리, 루트/탈옥, 전체 Intent/Binder 변형과 전체 의존성 CVE도 미검증이다.

## 구현 중 판단과 비용

- 과제별 RED/GREEN 뒤 전체 게이트를 수행하고 소스가 바뀐 실패 후보만 다시 만들었다.
  무관한 회귀를 최종 게이트까지 늦게 발견할 수 있는 비용이 있다.
- 별도 모델에 재위임하지 않았다. 작성자의 사각지대가 남는다.
- task-done의 중복 green 실행 대신 관측한 명령/로그/커밋을 ledger에 기록했다.
  기록 불일치 가능성을 해당 로그와 커밋으로 대조한다.
- ZIP64/multidisk를 거부하고 metadata 8MiB, 파일 2GiB, entry 256MiB,
  전체 비압축 1GiB, entry 10,000개로 제한한다. 더 큰 정상 형식은 추가 지원이 필요하다.
- 빌드 로그를 산출물 밖 0600 sibling 파일로 보존한다. 소유자가 삭제할 때까지 남으므로
  릴리스에는 첨부하지 않는다.
- 계획 목록에 빠진 AppInfo.version도 함께 갱신했다. 추가 파일 변경으로 실제 표시 버전
  불일치를 막았다.
- 일반 home 경로 휴리스틱은 ASCII 소유자명을 사용하고 exact 로컬 home 금지 검사를
  함께 강제한다. 미지의 제삼자 비ASCII 경로를 전부 검출하는 보장은 아니다.
- 빌드/태그 소스를 유지하고 결과 문서는 별도 문서 커밋으로 남긴다. 태그 안의 이 문서는
  준비 상태이며, PR 설명과 후속 main 문서에서 최종 결과를 확인할 수 있다.

미해결 Critical/Important 코드 발견과 이연한 Minor 발견은 없다. 남은 운영 위험과
검증하지 않은 범위는 위에 명시했으며 모든 보안 문제 부재를 보장하는 판정은 아니다.
